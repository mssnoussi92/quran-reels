Privacy Policy

Effective date: November 4, 2026

Quran Words Daily ("we") is a personal, non-commercial project. Its publishing tool, the application Quran Words Daily Publisher, uploads the project's own videos to the project's own accounts on Facebook, Instagram, TikTok and YouTube. This policy explains what data the tool and this website handle.

Who can use the application

Only the operator of Quran Words Daily signs in to the application, with the project's own accounts. The application does not offer sign-in to the public and does not act on behalf of other users.

Data we access

  • TikTok (Login Kit and Content Posting API): the basic profile of the project's own TikTok account (open ID, display name, avatar) to confirm which account is connected, and permission to upload videos to that account's inbox as drafts or to publish them.
  • Facebook and Instagram (Graph API): the project's own Facebook Page and its linked Instagram professional account, to publish reels.
  • YouTube (Data API): the project's own channel, to upload Shorts.

We do not access, collect or store data about viewers, followers or any other user, such as comments, messages, contacts or analytics.

How access tokens are stored

The access and refresh tokens issued by these platforms are stored only as encrypted secrets of the project's GitHub repository, used by the automated publishing job, and never shared, sold or published.

This website

This website uses no cookies, no analytics and no third-party trackers. The sign-in return page (tiktok-callback.html) displays the one-time authorization code in your browser only; it does not send it anywhere.

Revoking access and deleting data

Access can be revoked at any time from each platform's settings (for TikTok: Settings and privacy → Security and permissions → Apps and services). Revoking access makes the stored tokens unusable; we then delete them. For any request, write to quranwordsdaily@gmail.com.

Third-party platforms

Videos published on Facebook, Instagram, TikTok and YouTube are subject to those platforms' own privacy policies.

Changes

If this policy changes, the new version will be published on this page with a new effective date.
