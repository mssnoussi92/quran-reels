Connect YouTube

For the owner of this project. Two separate sign-ins, each with its own token:

  • Statistics: the nightly statistics read the channel's numbers (views, likes, comments, watch time), read only.
  • Uploads: the daily run uploads the calendar's Short to the channel. It can upload and read, it can neither change nor delete a video.

The page runs in your browser only: the client ID is not stored and is sent nowhere except to Google, inside the sign-in address.

Then

  1. Choose the Google account of the channel, then the channel Quran Words Daily if Google asks. « Google hasn't verified this app »: Advanced → Go to Quran Words Daily (it is your own app).
  2. Tick every box Google shows (statistics: YouTube, YouTube Analytics; uploads: manage your videos, view your account), Continue.
  3. Google sends you back to the callback page: copy the code.
  4. Within a few minutes, on GitHub: Actions → youtube-auth → Run workflow → paste the code.
