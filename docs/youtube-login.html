Connect YouTube statistics

For the owner of this project. Lets the nightly statistics read the channel's numbers (views, likes, comments, watch time), read only: nothing can be uploaded, changed or deleted. The page runs in your browser only: the client ID is not stored and is sent nowhere except to Google, inside the sign-in address.

Then

  1. Choose the Google account of the channel, then the channel Quran Words Daily if Google asks. « Google hasn't verified this app »: Advanced → Go to Quran Words Daily (it is your own app).
  2. Tick both boxes (YouTube, YouTube Analytics), Continue.
  3. Google sends you back to the callback page: copy the code.
  4. Within a few minutes, on GitHub: Actions → youtube-auth → Run workflow → paste the code.
