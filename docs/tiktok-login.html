Connect TikTok

For the owner of this project. Connects the TikTok account that receives the daily drafts. The page runs in your browser only: the client key is not stored and is sent nowhere except to TikTok, inside the sign-in address.

Then

  1. Sign in with the test account and allow user info and video upload.
  2. TikTok sends you back to the callback page: copy the code.
  3. Within a few minutes, on GitHub: Actions → tiktok-auth → Run workflow → paste the code.
